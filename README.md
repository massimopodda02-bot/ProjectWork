# Project Work - Corso di Laurea L-31
Segmentazione della clientela tramite K-Means e Streamlit.

### Come eseguire il progetto:
1. Installare le librerie: pip install streamlit pandas numpy scikit-learn seaborn matplotlib
2. Aprire un nuovo notebook in Google Colab. Aprire il file main.py con un editor di testo e incollare tutto il codice in un'unica cella di codice del notebook.
3. Eseguire la cella con il pulsante ▶. Lo script installa le librerie, genera i due CSV e avvia Streamlit.
4. Aprire il link stampato al termine della cella per visualizzare la dashboard.
